## Prerequisites
- Java Development Kit (JDK) 8 or higher
- Maven
- IDE (e.g., IntelliJ IDEA, Eclipse)
- WebDriver for the browser you are testing (e.g., ChromeDriver for Chrome)

## Installation
1. Clone the repository:
   ```sh
   git clone https://github.com/GB-Hemanth/Selenium-Swaglabs-project.git
   ```
2. Navigate to the project directory:
   ```sh
   cd Selenium-Swaglabs-project
   ```
3. Install the dependencies using Maven:
   ```sh
   mvn clean install
   ```
**Technologies:**
Selenium WebDriver
Java
Maven
**Patterns**
Fluent Page Object
PageFactory
TestNG

## Running Tests
To run the tests, execute the following command:
```sh
mvn test
```

## Project Structure
- `src/main/java`: Contains the main Java files.
- `src/test/java`: Contains the test files.
- `pom.xml`: Project Object Model file for managing project dependencies.
